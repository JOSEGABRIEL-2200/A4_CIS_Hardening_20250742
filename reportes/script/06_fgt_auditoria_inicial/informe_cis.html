2.2.1Ensure 'Password Policy' is enabled
Claves de administrador largas y complejas (12 caracteres, mayuscula, minuscula, numero y simbolo).
1NO CUMPLEpassword-policy disable, minimum-length 0config system password-policy
set status enable
set apply-to admin-password
set minimum-length 12
set min-lower-case-letter 1
set min-upper-case-letter 1
set min-non-alphanumeric 1
set min-number 1
set expire-status enable
set expire-day 90
end
2.2.2Ensure administrator password retries and lockout time are configured
Tras 3 intentos fallidos la cuenta se bloquea 15 minutos (contra fuerza bruta).
1NO CUMPLEthreshold 3, duration 60s (CIS: 3 intentos y 900 s)config system global
set admin-lockout-threshold 3
set admin-lockout-duration 900
end
